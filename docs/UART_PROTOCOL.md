# UART-протокол MCU ↔ FYT

Статус: попередній. Поля нижче взяті з хендоффу; алгоритм контрольної суми та значення `cmdType` для Raise ще не перевірені на логах (етап 3 у TODO).

## Формат пакета

```text
0x2E <cmdType> <len> <data[0..len-1]> <checksum>
```

| Поле | Розмір | Опис |
|---|---|---|
| `0x2E` | 1 байт | Заголовок пакета |
| `cmdType` | 1 байт | Тип команди (ідентифікатор групи даних Canbox) |
| `len` | 1 байт | Довжина поля `data` |
| `data` | `len` байт | Корисні дані |
| `checksum` | 1 байт | Контрольна сума — алгоритм не підтверджено |

## Що перевірити

- Алгоритм `checksum` (кандидати: інверсія суми `cmdType + len + data` по модулю 256, XOR) — звірити на кількох фреймах з `can_idle.log`.
- Перелік `cmdType`, які надсилає Raise на Megane 2, і які з них ігнорує `Callback_XXXX`.
- Напрямок ГП → Canbox (команди-запити), якщо такі є.
